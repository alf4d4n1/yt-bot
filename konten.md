## 🎨 VISUAL STYLE ANALYSIS

### Background Images
- **100% AI-generated** (kemungkinan Midjourney/DALL-E/Stable Diffusion)
- Style: **Cinematic, epic, painterly** — bukan foto realistis
- Color grading: **Warm amber/golden + misty cool blues/greens**
- Kualitas: Semi-realistic, sedikit dreamlike (khas AI)
- Setiap scene/segment pake **background berbeda** yang relevan dengan narasi
- Estimasi: **8-12 background images** untuk 1 video 90 detik

### Text Overlay Style
- **Font:** Bold, sans-serif, putih (ada shadow/outline untuk readability)
- **Posisi:** Center-bottom atau center frame
- **Ukuran:** Besar, mobile-friendly (bisa dibaca tanpa zoom)
- **Title card:** Font berbeda — gold metallic, serif, lebih dekoratif
- Text = **subtitle narasi**, bukan text terpisah dari audio
- Text muncul **sync dengan narasi** (word-by-word atau phrase-by-phrase)

### Transitions
- **Ken Burns effect** (slow zoom/pan) pada setiap background image
- Transisi antar scene: **crossfade atau cut** sederhana
- Tidak ada transisi fancy (no wipe, no slide, no spin)
- Durasi per background: **~8-12 detik** sebelum ganti

## 🔑 RUMUS KONTEN (Pattern yang Bisa Direplikasi)

### Formula Narasi (WAJIB ikuti):

```
1. HOOK (0-5s)
   "Banyak orang mengira [asumsi umum]. Padahal [fakta mengejutkan]."
   atau
   "Tahukah kamu [fakta shocking]?"
   atau
   "[Nama tokoh] melakukan [hal extreme]. Alasannya bikin merinding."

2. KONTEKS (5-20s)
   Setup dunia/era/situasi. Singkat, jelas, padat.
   Jangan info dump — pilih 2-3 fakta relevan saja.

3. ESKALASI (20-50s)
   Bangun tension. Cerita makin intens.
   Masukkan detail spesifik: nama, tahun, angka.
   "Ratusan ribu orang dipaksa bekerja" > "banyak orang bekerja"

4. TWIST/KLIMAKS (50-70s)
   Unexpected turn. Pengkhianatan, ironi, reveal.
   Ini jantung video — harus bikin penonton "WTF?!"

5. CONCLUSION (70-85s)
   1-2 kalimat ironis/filosofis yang summarize semuanya.
   "2000 tahun membangun, tapi jebol karena..."

6. PENUTUP (85-92s)
   Pertanyaan retoris untuk engagement.
   "Menurutmu... [X] atau [Y]?"
   + Subscribe CTA visual
```

### Formula Visual:

```
1. TITLE CARD (2-3s)
   - AI-generated epic image sesuai topik
   - Judul besar, gold/white, centered
   - Cinematic color grading

2. CONTENT SLIDES (per 8-12s)
   - 1 AI background per narasi segment
   - Ken Burns effect (slow zoom/pan)
   - Text overlay = subtitle narasi (sync)
   - Crossfade transition antar slide

3. OUTRO (5-7s)
   - Dark background
   - "Subscribe for more" text
   - Subscribe button visual
   - Channel name/logo
```

## 🛠️ PRODUCTION PIPELINE (Untuk Bot)

### Step-by-step untuk reproduce:

```
INPUT (dari user/kurator):
├── Topik sejarah (1 kalimat)
├── 5-10 poin cerita (outline)
└── [OPSIONAL] Gambar referensi

BOT PIPELINE:
│
├── 1. SCRIPT GENERATION (AI - Gemini/Claude)
│   ├── Expand outline → narasi 200-250 kata
│   ├── Ikuti formula: Hook → Konteks → Eskalasi → Twist → Conclusion → Penutup
│   ├── Bahasa Indonesia, storytelling tone
│   └── Output: script.txt
│
├── 2. IMAGE GENERATION (AI - Gemini/DALL-E/Stable Diffusion)
│   ├── Parse script → identifikasi 8-12 scene/segment
│   ├── Generate prompt per scene
│   ├── Generate 1080x1920 portrait images
│   ├── Style: cinematic, epic, warm amber + cool mist
│   └── Output: images/scene_01.jpg ... scene_12.jpg
│
├── 3. TITLE CARD GENERATION
│   ├── Background: image scene paling epic
│   ├── Overlay: judul topik (gold metallic font, centered)
│   └── Output: title_card.jpg
│
├── 4. TTS NARRATION (AI - Google/ElevenLabs/Edge)
│   ├── Input: script.txt
│   ├── Voice: Indonesian male/female, natural
│   ├── Speed: ~2.5 kata/detik
│   └── Output: narration.mp3
│
├── 5. SUBTITLE GENERATION
│   ├── Whisper/forced alignment dari narration.mp3
│   ├── Word-level timing
│   ├── Format: SRT/ASS dengan styling (bold, white, shadow)
│   └── Output: subtitles.ass
│
├── 6. VIDEO RENDER (FFmpeg)
│   ├── Combine: images + Ken Burns + crossfade
│   ├── Sync: narration timing → image switches
│   ├── Overlay: subtitles (burned in, styled)
│   ├── Add: background music (low volume)
│   ├── Add: outro/subscribe card
│   ├── Export: 1080x1920, 30fps, h264
│   └── Output: final_video.mp4
│
├── 7. SEO METADATA (AI)
│   ├── Title (max 100 chars, clickbait tapi akurat)
│   ├── Description (500 chars, keywords)
│   ├── Tags (30 tags, mix ID+EN)
│   ├── Hashtags (#sejarah #history #shorts)
│   └── Output: metadata.json
│
└── 8. UPLOAD (YouTube Data API)
    ├── Upload video
    ├── Set metadata
    ├── Set thumbnail (frame title card)
    └── Schedule/publish
```
