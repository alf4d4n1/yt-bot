[ 3. DIREKTORI & SUMBER ASET LOKAL (UNTUK ENGINE BOT) ]
Struktur folder di dalam D:\ALL BOTT\YT-bot-main\:

YT-bot-main/
  ├── assets/
  │    ├── backgrounds/    -> Simpan gambar AI 1920x1080 (.jpg/.png)
  │    ├── music/          -> Simpan file musik instrumental (.mp3/.wav)
  │    ├── ambience/       -> Suara hujan, perapian, kedai kopi (.mp3/.wav)
  │    └── overlays/       -> Efek overlay asap kopi, rintik hujan (.mp4 transparan)
  ├── output/              -> Hasil render video final MP4 (1 Jam) siap upload
  └── scripts/             -> Script python & tools otomatisasi

Sumber Sound Ambience Gratis & 100% Legal:
1. Freesound.org:
   - Search: "rain gentle interior window", "fireplace burning crackle", "cafe chatter murmur distance", "forest stream water".
2. Pixabay.com/sound-effects:
   - Filter: Nature, Ambient, Foley (Lisensi bebas royalti selamanya).
3. YouTube Audio Library (Bawaan YouTube Studio):
   - Masuk ke studio.youtube.com -> Audio Library -> Sound Effects (100% aman anti klaim hak cipta).
